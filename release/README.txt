# FileHub v0.1.5 — 局域网文件共享

## 是什么

零配置的点对点文件共享工具。每台电脑跑一个程序，自动发现同网段的其他机器，
点一下就能下载对方的文件。告别 Windows 共享目录「找不到对方」的烦恼。

## 怎么用

1. 双击运行 `filehub-windows-amd64.exe`（其他系统选对应文件）。
2. 首次运行会自动创建 `upload`（你要分享的文件放这里）和 `download`
   （下载的文件落到这里）两个目录。
3. 浏览器打开 `http://本机IP:36774`（程序启动时会在窗口里打印地址）。
4. 左侧「在线机器」会列出同网段其他开了 FileHub 的机器，点击即可浏览
   对方 upload 目录，点「下载」保存到自己的 download 目录。

## 特性

- ✅ 自动发现同网段机器（UDP 广播）
- ✅ 查看对方文件名 / 大小 / 修改时间
- ✅ 支持子目录浏览（点进去/返回上级）
- ✅ 断点续传（中断后接着下）
- ✅ 下载中可暂停 / 继续 / 终止
- ✅ 相同文件秒传跳过（文件名+大小+SHA-256 一致）
- ✅ 下载进度实时显示、完成 / 损坏 / 失败状态
- ✅ SHA-256 完整性校验，损坏会标红

## 防火墙提示

Windows 首次运行会弹防火墙提示，请**允许访问**（需放行 TCP 36774 + UDP 36774）。

## 各平台文件

| 文件 | 平台 |
|------|------|
| `filehub-windows-amd64.exe` | Windows 64 位（绝大多数 PC） |
| `filehub-windows-arm64.exe` | Windows ARM64（骁龙笔记本等） |
| `filehub-darwin-arm64` | macOS Apple Silicon (M 系列) |
| `filehub-darwin-amd64` | macOS Intel |
| `filehub-linux-amd64` | Linux 64 位 |
